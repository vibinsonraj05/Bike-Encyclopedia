# 🏍️ Bike Encyclopedia

An interactive web-based bike encyclopedia that allows users to explore different motorcycles and scooters through images and descriptions. Users can search for bikes and click on images to view detailed information in a premium animated popup.

## ✨ Features

- Explore 40 different bikes and scooters
- Search bikes by name
- Interactive bike image gallery
- Premium popup for bike details
- Smooth popup animations
- Click outside to close the popup
- Keyboard support using the Escape key
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Bike-Encyclopedia.git
```

### 2. Navigate to the project folder

```bash
cd Bike-Encyclopedia
```

### 3. Run the application

Open `index.html` in your web browser.

**Note:** Keep the `asset` folder in the same directory as the HTML file to ensure all bike images load correctly.

## 🎯 How to Use

1. Open the application in your browser.
2. Browse the available bikes.
3. Use the search bar to find a specific bike.
4. Click on any bike image to open its details.
5. Close the popup using the close button, outside click, or Escape key.
